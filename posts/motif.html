MOTIF: using LLM reasoning to change a cold item’s neighbours

Zijun Wang · Cold-start recommendation · 3 min read

Why MOTIF uses motivation semantics to reconstruct graph edges, how direct fusion compares, and where leakage and false semantic links can enter.

Read the paper · PDF WISE 2026

An item with content but no graph history

A new item may have a useful description and image while remaining poorly connected to the interaction graph. Good content features alone do not guarantee that useful collaborative information can reach it.

MOTIF uses LLM-derived motivation semantics to reconstruct item connections. The design question is where to introduce that information: directly into a prediction vector, or into the topology used for propagation.

From motivation to an edge

The model generates item motivation descriptions from item-side content. User motivation descriptions use only training-visible interaction histories.

Candidate item neighbours are retrieved using a mixture of motivation-semantic similarity and raw multimodal similarity. An offline LLM relation prior then scores functional relationships within that candidate set.

aij = α sim(si, sj) + (1 − α) sim(mi, mj)
wij = aij + β rij

Each item keeps its highest-scoring neighbours. These weighted item edges are combined with the user–item interaction graph for LightGCN-style propagation.

The candidate restriction matters computationally: the LLM does not need to score every pair of items. It also creates a retrieval bottleneck, since a useful pair outside the candidate set cannot be recovered by the relation prior.

The direct-fusion alternative

One simpler choice is to concatenate LLM semantic embeddings with graph embeddings and predict from that combination. The paper tests this as Direct-Fusion, alongside a graph built from similarity alone.

The full model outperforms both alternatives on all three datasets. That supports using the semantic signal to reshape propagation rather than relying on direct fusion in this implementation.

The distinction is mechanistic. Direct fusion changes what the final predictor sees. Reconstruction changes which items can exchange information throughout graph propagation.

This is a comparison of implemented alternatives, not evidence that every graph reconstruction method is better than every semantic fusion method. The graph and training objectives are still specific design choices.

What the cold-start result covers

The paper defines extreme-cold users as having one or two visible training interactions. Cold-item evaluation masks item training interactions while retaining item content; the masked interactions are held for validation and testing.

On Amazon-Baby cold items, MOTIF obtains 0.0613 Recall@20 versus 0.0488 for LMMRec, about a 25.6% relative gain. These are cold-subset results, distinct from the overall scores above.

The masking protocol is reproducible, but it does not reproduce every aspect of an item arriving after deployment. A temporal evaluation would additionally test changing catalogues and the age of generated motivation descriptions.

Semantic plausibility is another limit. Two items can share a usage description without serving the same users. A mistaken edge can spread an unhelpful signal through several propagation layers.

I would inspect edge quality alongside ranking accuracy, especially for the coldest items. Comparing candidates, selected edges, and propagation effects would help identify whether an error begins in retrieval or relation reasoning.

Leakage checks belong at each generation input: user reasoning must exclude held-out interactions, and item reasoning must use only the item-side information allowed by the evaluation.
